Acme Metrics API

REST API reference — version 2.5.0 (stable). Last updated 2026-10-03.

Authentication · Rate limits · Endpoints · Changelog

Authentication

All requests require a Bearer token in the Authorization header. Tokens are issued from the developer console and expire after 90 days of inactivity.

curl -H "Authorization: Bearer $TOKEN" https://api.acme-metrics.example/v2/series

Rate limits

The free tier allows 120 requests/minute and 10,000 requests/day. Team plans allow 600 requests/minute. Responses include X-RateLimit-Remaining and X-RateLimit-Reset headers.

Endpoints

MethodPathDescription
GET/v2/seriesList metric series for the account
GET/v2/series/{id}Read a single series
POST/v2/series/{id}/pointsAppend data points (max 500 per call)
POST/v2/series/{id}/rollupCompute daily rollups for a window
DELETE/v2/series/{id}Delete a series and its history
