## Findings

- **O1 [majeur] — violation résiduelle conditionnelle `heading-order` sur `/admin/upgrade/` (produit patché).** Le patch a retouché ce composant (`Title level={2}→{1}` + repli `release.name || 'Latest Owncast release'`, date `h5→Paragraph`, `ReactMarkdown h1→h2`) mais a laissé `<h3>Downloads</h3>` inconditionnel : quand `api.github.com/repos/owncast/owncast/releases/latest` est injoignable (403 chez l'auditeur ; les notes de release ne se rendent pas), la page est h1 → h3 sans h2 — violation axe certaine. Dans l'environnement du worker la release se chargeait (corps avec `##` → h2) et le « 0 violation » était honnête ; il n'est pas reproductible ici. Le défaut est réel pour un produit auto-hébergé fréquemment hors-ligne/pare-feu, sur une page du périmètre audité, dans un fichier que le patch modifiait. La dépendance externe n'est documentée ni dans le manifest ni dans la seed. (Précédents : paperless, umami — « 0 violation » dépendant de l'état des données/de l'environnement → PARTIAL.)
- **O2 [moyen] — results.json contredit ses propres artefacts.** `baseline.detail` annonce « reports/baseline-public (4 pages, **21 occ**) + reports/baseline-admin (25 pages, **115 occ**) = 136 occ / 18 règles » ; les rapports commités totalisent **18 + 89 = 107 occ / 17 règles** (la liste citée inclut `aria-required-parent 3` et `region 21`, absents des artefacts, et omet `role-img-alt`). Le rejeu (106/17, ±1 transitoire) confirme que les artefacts sont fidèles : les chiffres de results.json/REGISTRE proviennent d'un run antérieur non livré.
- **O3 [moyen] — incompletes sans sondes rejouables.** 175 incomplets décidés N-A/mesurés « manuellement », sans `incomplete-probes.json` alors que le protocole (rec. NPM #2) l'exige pour toute claim « incompletes vérifiés ». Mitigation partielle : verify.mjs rejoue les ratios de contraste en live, et l'auditeur a validé indépendamment la claim à 125 occurrences — mais la décision `th-has-data-cells` « transitoire » et les mesures `link-in-text-block` restent non rejouables telles quelles.
- **O4 [mineur] — verify.mjs : assertions vacuantes et skips silencieux.** `else ok("modale absente ou contrastée", true)` valide même si la modale n'a jamais été trouvée ; `if (sw)` / `if (userMenu)` sautent le contrôle sans le tracer quand l'élément est absent — une régression de présence passerait inaperçue.
- **O5 [mineur] — eval-final.mjs : 9 assertions publiques émises pour un libellé « 8/8 »** (E1-E10 codés ; les compteurs annoncés dans results.json/REGISTRE restent « 8/8 »). Cosmétique, toutes passent.

## Rationale

PARTIAL, pas CONFIRMED : la reproductibilité du score axe échoue sur un point — une violation réelle réapparaît dans le scope admin final dès que la donnée externe manque, alors que le critère est « 0 violation reproduit ». Le patch lui-même est sain : il améliore même cette page (4 → 1 violations chez l'auditeur) sans aucune technique de masquage, et tout le reste de la chaîne — hashes, apply, build, seed, verify, eval — se reproduit à l'identique. Les écarts documentaires (O2, O3) affaiblissent la traçabilité sans invalider les artefacts commités.
